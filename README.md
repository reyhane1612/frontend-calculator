# Calculator

A simple calculator web app with a UI inspired by the calculator, built with vanilla HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations: addition, subtraction, multiplication, division
- Percentage calculation
- Positive/negative toggle (+/-)
- Clear (C) and backspace (eraser) buttons
- style status bar (clock, wifi, battery icons) for a native look

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla, no frameworks)

## Prerequisites
No installation or build tools required — this is a static project.

## Running the Project
Simply open `index.html` in your browser.
